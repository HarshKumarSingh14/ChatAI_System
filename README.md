# 🤖 AI Chatbot System (MERN Stack)

A production-ready, highly-polished AI Chatbot web application built with the **MERN** stack and **Vite**, featuring an intuitive UI/UX inspired by modern commercial AI interfaces. It includes robust security measures like Google OAuth 2.0, TOTP-based Two-Factor Authentication (2FA), and seamless profile management.

## ✨ What's New & Core Features

* **🔐 Advanced Authentication & Security:**
  * **Google OAuth 2.0 Integration:** Quick and secure sign-in/sign-up using Google accounts.
  * **TOTP-Based 2FA:** Enhanced account protection using authenticator apps (Google Authenticator, Authy) powered by `speakeasy`.
  * **Password & Session Security:** Secure password update flows and device session handling.

* **👤 Seamless Profile Management:**
  * **Instant Avatar Upload:** Real-time profile photo cropping and upload directly integrated with **Cloudinary**.
  * **Inline Editing:** Quick name and profile updates without annoying multi-step edit modes.

* **📊 Data & Privacy Control:**
  * **Date-Wise Chat Export:** Export your complete conversation history (including both user inputs and AI responses) neatly structured and grouped by date into a JSON file.
  * **History Cleanup:** Option to securely delete all conversation history with one click.

* **🎨 Premium UI/UX Design:**
  * Built with **Tailwind CSS** and **Lucide Icons**.
  * Fully responsive design with a polished **Dark/Light/System theme toggle**.
  * Smooth micro-interactions, suggestion cards grid, and floating interactive chat input bars.

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite 6.4.3, Tailwind CSS, Zustand (State Management), Lucide React.
* **Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose.
* **Services & Security:** Cloudinary (Media Storage), Google Auth, Speakeasy (TOTP 2FA), JWT Authentication.
